# 瞬間英作文アプリ — セットアップ手順

iPhoneのホーム画面から使う、自分用の瞬間英作文アプリです。費用は無料で、有効期限も入れ直しもありません。

## 1. Gemini APIキーを取る（5分）
1. MacかiPhoneで https://aistudio.google.com/apikey を開き、Googleアカウントでログインする
   - プロジェクトは、お支払い情報を登録していない新しいものを選ぶ（無料枠のまま使うため）
2. 「Create API key（APIキーを作成）」を押す
3. 表示された `AQ.` （または `AIza`）で始まる文字列をメモしておく（アプリの初回起動時に貼り付ける）
※ 無料枠では、送った練習文がGoogleのAI改善に使われることがあります。

## 2. GitHub Pagesで公開する（10分・Macのブラウザで）
1. https://github.com でアカウントを作る（無料）
2. 右上の「＋」→「New repository」
   - Repository name：好きな名前（例 `eng-app`）
   - **Public** を選ぶ（無料で公開するのに必要。APIキーはファイルに入っていないので安全です）
   - 「Create repository」
3. 表示された画面の「uploading an existing file」をクリック
4. このフォルダの**中身のファイルを全部**（index.html, app.js など。フォルダごとではなく中身）ドラッグ＆ドロップ →「Commit changes」
5. リポジトリの「Settings」→ 左メニュー「Pages」
   - Source：「Deploy from a branch」
   - Branch：`main`、フォルダ `/ (root)` →「Save」
6. 1〜2分待つと、同じ画面の上に `https://あなたのユーザー名.github.io/eng-app/` というURLが出る

## 3. iPhoneのホーム画面に追加する
- **Safari**：URLを開く → 下の共有ボタン（□に↑）→「ホーム画面に追加」
- **Chrome**：URLを開く → 右上（またはアドレスバー横）の共有ボタン →「ホーム画面に追加」

ホーム画面のアイコンから起動すると、アプリと同じように全画面で動きます。
初回にAPIキーを貼り付け、マイクの使用を「許可」してください（iOSでは起動のたびにマイクの許可を聞かれることがあります）。

## 4. パートナーのiPhoneに入れる
同じURLを送って、3と同じ手順でホーム画面に追加するだけです。
学習記録は端末ごとに別々です。APIキーはパートナーも自分の分を1で取るのがおすすめです（1つのキーを共有すると、1日の無料回数を2人で分け合うことになります）。

## 使い方のポイント
- 最初に12問のレベル測定 → その後は「今のレベルより少し上」の文が出て、答えるたびにレベルが上下します
- 70点未満の文は翌日以降の復習に回り、設定した回数だけ連続で80点以上を取ると復習リストから外れます
- 用意した200文を解き終えると、AIがあなたのレベルと、まだ使えていない単語に合わせて新しい文を作ります
- 声がうまく認識されない場所では「キーボードで答える」に切り替えてください（キーボードのマイクボタンで音声入力もできます）
- 機種変更の前には「設定 → バックアップ → 書き出す」で記録を保存し、新しい端末で「読み込む」

## アプリを更新するとき
変更したファイルをGitHubに上書きアップロードし、`sw.js` の `VERSION = 'v1'` を `'v2'` のように1つ上げてください。アプリを2回開き直すと新しい版になります。

## 例文を自分で足したいとき
`sentences.js` の配列に `{"id":"m001","lv":5,"sc":"仕事","ja":"日本語","en":"English","w":[]}` の形で追加できます（`lv` は1〜10、`sc` は 日常/食事/買い物/旅行/仕事/会議/雑談/気持ち/健康・病院/電話・メール のどれか）。
